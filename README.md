# TKL_macro

TikTok Lite の動画を、上スワイプで自動で次へ進める Android アプリ(非公式)です。
3 分以上の動画だけをじっくり見て、短い動画や広告は素早く飛ばします。

**ダウンロードと使い方: https://miku-46.github.io/tl-macro/**

- 対応: Android 7.0 以上(動画の長さの判定は Android 11 以上)
- 読み取るのは TikTok 系アプリの画面だけです。内容は保存も送信もしません。このアプリは通信の権限を持っていません。
- 自動操作は、TikTok の利用規約に反する可能性があります。自己責任でお使いください。
- TikTok とは無関係の、非公式のアプリです。
